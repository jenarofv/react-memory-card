# React Memory Card App

Created for [The Odin Project](https://theodinproject.com)

## Installation

Clone the repo, open its directory with a terminal, and run `npm install`.

## Concepts

Made using React, while practicing core concepts, such as:

- States
- Side Effects
- Asynchronous functions (`fetch`)
- responsive design
